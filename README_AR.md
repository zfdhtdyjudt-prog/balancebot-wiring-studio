# BalanceBot Wiring Studio — حزمة محلية جاهزة لـ VS Code

هذه النسخة **موقع محلي حقيقي يعمل في المتصفح** من ملفات HTML/CSS/JavaScript فقط. لا توجد خدمة سحابية، ولا قاعدة بيانات، ولا نشر تلقائي، ولا حاجة إلى React أو npm.

## ماذا ستشاهد عند التشغيل؟

ستفتح واجهة فيها محرر JSON ورسم SVG حي لمشروع BalanceBot. يوجد تبويبان مستقلان:

- **Arduino Standalone** — Arduino Uno R3، MPU6050، L298N، محركان، HC-SR04، LEDs، بطارية.
- **ESP32 Standalone** — ESP32 DevKit، MPU6050، L298N، محركان، HC-SR04، LEDs، بطارية، ومقسم جهد Echo.

كل تبويب يعرض أرقام الأرجل، أسماء الإشارات، أسلاكًا ملونة، ورقة مواصفات، وتحذيرات السلامة.

## التشغيل الموصى به: VS Code + Go Live

1. فك ضغط الملف `balancebot-wiring-studio-local.zip`.
2. افتح VS Code.
3. اختر **File → Open Folder** وافتح المجلد `balancebot-local` نفسه، وليس ملف ZIP.
4. افتح `index.html`.
5. ثبّت إضافة **Live Server** من متجر VS Code إذا لم تكن موجودة.
6. اضغط بزر الفأرة الأيمن على `index.html` ثم اختر **Open with Live Server**، أو اضغط **Go Live** أسفل VS Code.
7. ستفتح الصفحة في المتصفح. اترك VS Code مفتوحًا حتى يستمر Live Server.

> لا تضغط على `app.js` أو ملف JSON لتشغيل الموقع؛ الملف الذي يبدأ منه الموقع هو `index.html`.

## تشغيل احتياطي بدون Live Server

إذا لم تظهر لك إضافة Go Live:

- على Windows: انقر مرتين على `start-local.bat`.
- على Linux/macOS: افتح Terminal داخل المجلد وشغّل:

```bash
chmod +x start-local.sh
./start-local.sh
```

ثم افتح `http://127.0.0.1:4173` في المتصفح.

إذا كان Python غير مثبت، ثبّت إضافة Live Server في VS Code بدلًا من ذلك. لا تحتاج الحزمة إلى تنزيل مكتبات JavaScript من الإنترنت.

## استخدام محرر JSON

1. اختر تبويب Arduino أو ESP32.
2. عدّل الكود في صندوق **كود الدائرة**.
3. مع تفعيل **رسم تلقائي بعد التعديل** سيعاد الرسم تلقائيًا، أو اضغط **رسم المخطط** يدويًا.
4. إذا كان JSON غير صحيح أو كان هناك `id` مكرر أو توصيل يشير إلى مكوّن غير موجود، ستظهر رسالة خطأ ولن يتم استبدال الرسم الصحيح.
5. زر **فتح JSON** يقرأ ملف JSON من جهازك.
6. زر **تصدير SVG** يحفظ الرسم الحالي كملف متجهي قابل للتكبير.
7. زر **تنزيل JSON** يحفظ الكود الحالي.
8. زر **إرجاع العينة** يعيد عينة النمط الحالي.

### قاعدة مهمة للتوصيلات

كل عنصر داخل `components` يحتاج إلى `id` فريد. يجب أن تستخدم قيمتا `from` و`to` في `connections` أحد هذه الـ IDs. مثال:

```json
{
  "from": "arduino",
  "to": "mpu",
  "label": "A4 → SDA",
  "color": "i2c"
}
```

الألوان المدعومة: `power`, `gnd`, `i2c`, `control`, `sensor`, `motorL`, `motorR`, `signal`.

## الملفات

- `index.html` — واجهة الموقع.
- `styles.css` — التصميم المتجاوب.
- `app.js` — محرك JSON → SVG، التحقق، التحميل والتصدير.
- `samples/arduino-standalone.json` — مثال Arduino.
- `samples/esp32-standalone.json` — مثال ESP32.
- `start-local.bat` — تشغيل اختياري على Windows.
- `start-local.sh` — تشغيل اختياري على Linux/macOS.
- `check-project.py` — فحص وجود الملفات وصحة عينات JSON.
- `.vscode/settings.json` — إعدادات Live Server اختيارية.

## كيف أتأكد أنه يعمل فعليًا؟

بعد فتح الموقع:

- يجب أن ترى مخطط Arduino مباشرة عند البداية.
- اضغط تبويب ESP32؛ يجب أن يتغير المخطط وورقة الأرجل.
- غيّر `title` في JSON ثم اضغط الرسم؛ يجب أن يتغير عنوان المخطط.
- احذف فاصلة من JSON؛ يجب أن يظهر خطأ واضح ولا ينهار الموقع.
- أعد العينة أو أصلح JSON؛ يجب أن يعود الرسم.
- اضغط **تصدير SVG**؛ يجب أن ينزل ملف SVG للرسم المعروض.

ولفحص الحزمة من Terminal قبل تشغيلها:

```bash
python3 check-project.py
```

في Windows يمكن تشغيل الأمر نفسه من PowerShell إذا كان Python مثبتًا.

## ملاحظات هندسية

الرسم مبني على توصيلات المشروع الموثقة في `README_AR.md` و`PINOUT_AND_POWER_AR.md`. لكنه لا يستطيع إثبات اتجاه دوران المحركات أو سلامة لوحة حقيقية من خلال المتصفح. افصل البطارية قبل تغيير الأسلاك، اختبر العجلات مرفوعة، لا توصل 12V إلى Arduino أو ESP32 أو MPU6050، واستخدم مقسم جهد Echo مع ESP32.
