# قواعد الرسم التخطيطي النظيف

الإصدار 3.1 من عينة `arduino-only.json` يستخدم تخطيطًا متباعدًا وممرات orthogonal قابلة لإعادة التوجيه:

- Arduino Uno في المركز.
- البطارية، مفتاح الطاقة، والمكثف في الحزام العلوي.
- L298N في الحزام السفلي، والمحركان أسفله.
- Potentiometer وBuzzer وIR وLEDs في الجانب الأيسر.
- MPU6050 وHC-SR04 في الجانب الأيمن.
- كل مكوّن له مستطيل مستقل وpadding لا يقل عن 48px في إعدادات المشروع.
- لا يعتمد مسار السلك على خط منتصف عشوائي؛ يختار renderer ممر X أو Y لا يتقاطع مع مستطيلات المكونات، مع تجاهل مستطيل المصدر والهدف عند نقطة التوصيل فقط.
- `routeLane` في JSON هو تفضيل للممر، وليس تصريحًا بمروره فوق مكوّن؛ الخوارزمية تستبعده إذا سبب تصادمًا.
- الطاقة حمراء، الأرضي أسود، I2C بنفسجي، التحكم برتقالي، الحساسات ذهبية، والمحركات خضراء.

## تسميات Arduino Uno

الـregistry يستخدم الاسم المطبوع على اللوحة:

- Digital: `2`, `4`, `7`, `8`, `12`, `13`.
- PWM: `~3`, `~5`, `~6`, `~9`, `~10`, `~11`.
- Serial: `RX←0`, `TX→1`.
- Analog/I2C: `A0`, `A1`, `A2`, `A3`, `A4`, `A5`.

## التحقق

قبل كل commit تُشغّل:

```bash
python3 check-project.py
node --check app.js
python3 -m json.tool components.json
```

الفحص لا يكتفي بصحة JSON؛ يتحقق من أن كل endpoint في wires موجود في registry وأن كل sample قابل للتحميل.
